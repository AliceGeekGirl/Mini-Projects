# Mini Projects 🚀

Repositório destinado ao desenvolvimento, documentação e evolução de **pequenos projetos práticos, protótipos e experimentos** na área de tecnologia, reunindo soluções de software e eletrônica desenvolvidas ao longo da minha jornada acadêmica e profissional.

## 🎓 Formação
- **Universidade:** Centro Universitário SATC (UNISATC)
- **Curso:** Engenharia de Computação
- **Foco:** Desenvolvimento de software, arquitetura de sistemas, banco de dados e prototipagem eletrônica.

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Linguagens de Programação:** C, C++, Python
- **Eletrônica & Embarcados:** Arduino IDE, prototipagem de circuitos e sensores
- **Banco de Dados:** Modelagem Relacional, SQL (DDL/DML), PostgreSQL
- **Ambientes de Desenvolvimento:** VS Code, GitHub Codespaces, Dev-C++
- **Modelagem e Diagramação:** Draw.io (Diagramas Entidade-Relacionamento)

## 📁 Estrutura do Repositório
O repositório está organizado por tecnologias e áreas de aplicação:

- `ArduinoIDE/` — Projetos e protótipos envolvendo microcontroladores, sensores e programação embarcada em C/C++.
- `C-Cplusplus/` — Projetos práticos e aplicações de console focadas em lógica, algoritmos e gerenciamento de memória.
- `Python/` — Pequenas aplicações, automações e scripts práticos desenvolvidos em Python.
- `SQL/` — Projetos de modelagem física, scripts DDL/DML e consultas estruturadas.
- `Draw.io/` — Diagramas de arquitetura, fluxogramas e modelos Entidade-Relacionamento (DER) dos projetos.
